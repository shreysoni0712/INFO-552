# INFO-552

## Developer: Shrey Soni

## Project: Community Care Connect - Healthcare Resources for Philadelphia

## Description:

Community Care Connect is a web application that provides healthcare resources and information to residents of Philadelphia. The application is designed to help residents find and access healthcare services, including clinics, pharmacies, and mental health resources. The application also provides information on insurance coverage and financial assistance programs.

## Features:

- Find a Clinic
- Appointment Help
- Medications
- Mental Health
- Insurance Coverage
- Financial Assistance
